# T88/CMT フォーマット アナライザー & バイナリダンプ

PC-8801などのレトロPCで利用されるカセットテープイメージファイル（`.t88` および `.cmt`）の構造解析と、バイナリダンプを行うためのGUIツールです。
Pythonの標準ライブラリ（Tkinter）のみで実装されており、外部依存パッケージなしで軽量に動作します。

## ✨ 主な機能 (Features)

- **T88フォーマットの構造解析**
  - T88ファイル内の構造タグ（Blank, Data, Space, Mark 等）をパースし、Treeviewで一覧表示。
  - 再生時間（Ticks / ミリ秒）やデータサイズ、ボーレート（600/1200bps）を自動計算して表示。
- **CMTフォーマット対応**
  - 構造タグを持たない純粋なベタデータ（CMT）のフルダンプと解析に対応。
- **インタラクティブなバイナリダンプ**
  - 全体ダンプまたはタグ単体のHex＆ASCIIダンプを表示。
  - ダンプ画面の任意のバイトをクリックすると、クリック位置の絶対オフセット値、2進数ビット表現、所属するタグ情報などが下部のステータス解析ペインに表示されます。
- **ハイライト連動機能**
  - リストからタグを選択すると、全体ダンプ上でそのタグが占有しているバイナリ領域が黄色くハイライトされます。

## 💻 動作環境 (Requirements)

- Python 3.6 以上
- Tkinter が有効なPython環境（Windows版Pythonには標準で付属。Linux等の一部環境では別途 `python3-tk` などのインストールが必要な場合があります）

## 🚀 インストール手順 (Installation)

安全に実行するために、Pythonの仮想環境（venv）を構築して実行することを推奨します。

### 1. 仮想環境 (venv) の作成と有効化

**Windows の場合 (コマンドプロンプト / PowerShell):**
```cmd
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux の場合:**
```bash
python3 -m venv venv
source venv/bin/activate
```
*(※ 環境が有効化されると、プロンプトの先頭に `(venv)` が表示されます)*

### 2. アプリケーションの起動
本ツールは外部ライブラリ（`requirements.txt` 等による `pip install`）を必要としません。仮想環境が有効な状態で、以下のコマンドを実行するだけで起動します。

**Windows の場合:**
```cmd
python main.py
```

**macOS / Linux の場合:**
```bash
python3 main.py
```
*(※ ファイル名が `main.py` ではない場合は、実行するファイル名に読み替えてください)*

## 📁 ファイル構成

- `main.py`
  - アプリケーションのエントリーポイント。メインGUI（T88GuiDumper）の定義およびウィジェットの配置を行います。
- `t88_widgets.py`
  - 16進数ダンプ表示、ピンポイントでのバイトハイライト機能、クリック座標からのオフセット計算機能を持つカスタムテキストウィジェットクラス（`DumpTextArea`）を定義しています。
- `t88_parser.py`
  - T88 / CMTファイルの読み込み、バイナリパース、タグ抽出、メタデータの計算などを行うデータ処理ロジッククラス（`TapeImageParser`）を定義しています。

## 📖 使い方 (Usage)

1. 画面左上の **「ファイルを開く」** ボタンをクリックし、解析したい `.t88` または `.cmt` ファイルを選択します。
2. **T88ファイル** の場合：
   - 「T88 構造解析ビュー」タブが開き、左側にタグ一覧が表示されます。
   - タグを選択すると、右側にそのタグのデータ部のみがダンプされ、下部ペインに詳細（Ticks、ボーレート等）が表示されます。
3. **CMTファイル** の場合：
   - タグが存在しないため「ファイル全体ダンプ」タブが自動的に開きます。
4. **ダンプ画面のクリック**：
   - Hexダンプ内の任意のバイトをクリックすると、その1バイトの詳細情報（2進数など）と、所属するタグブロックの情報が下部に表示されます。

## 🚪 仮想環境の終了
作業が終わったら、以下のコマンドで仮想環境を終了できます。
```bash
deactivate
```
